# 2026 누들대전축제 홍보 웹페이지 (AX 실습)

대전누들축제(noodle-dj.com)를 바탕으로 만든 실습용 홍보 웹페이지입니다.
축제 소개, 대전 면 요리의 역사, 시간별 이벤트 소개를 담았습니다.

각 날짜 폴더의 `index.html`을 브라우저로 열면 그날 마지막 상태의 페이지를 볼 수 있습니다.
