1080×1350(4:5) 세로형 8장, 친근한 정보 공유 톤입니다.

각 날짜 폴더에는 그날 작업이 끝난 상태의 카드 이미지 8장(`card-01.png` ~ `card-08.png`)이 있습니다.
같은 폴더의 `index.html`을 브라우저로 열면 넘겨보기와 전체 보기로 확인할 수 있습니다.

## 2026-11-05 · `2026-11-05/`

- 공식 홈페이지 내용 확인 후 카드뉴스 기획 (리플렛은 작년 자료라 제외, 홈페이지 내용만 사용)
- 장수는 8장, 톤은 공식 홍보 톤과 비교한 뒤 친근한 정보 공유 톤으로 결정
- 8장 전체 문구 작성. 홈페이지에 설명이 없는 프로그램은 내용을 지어내지 않고 시간만 표기
- 홈페이지 메인 비주얼을 벤치마킹한 디자인
  - 하늘색 배경, 상단 축제 깃발 가랜드, 하단 도시 실루엣과 가을 나무, 은행잎·단풍잎 장식
  - 주황·갈색의 굵은 제목(Black Han Sans), 갈색 테두리와 그림자의 스티커 느낌 박스
  - 문구 속 이모지는 기기마다 다르게 보일 수 있어 같은 의미의 아이콘으로 교체
- 인스타그램처럼 옆으로 넘겨볼 수 있도록 8장을 가로 순서로 배치하고 넘겨보기 미리보기 추가
- 3장 제목을 단어 단위로 줄바꿈 ("축제 정보 / 저장해두기")
- 3·5·6·7·8장 제목 끝에 느낌표 추가

## 2026-11-06 · `2026-11-06/`

- 가을 면 축제에 맞는 배경 방향 논의 후, 노을 하늘 + 단풍 강화 조합으로 1차 변경
  - 깃발 사이 노란 전구, 빨간 단풍나무·노란 은행나무, 바닥 낙엽 더미, 양옆 단풍잎 추가

- 2장 본문을 글자 단위가 아닌 단어 단위로 줄바꿈되게 수정
- 배경을 노을 대신 낮처럼 밝은 하늘로 변경 (지는 해 대신 흰 구름, 건물은 밝은 보라색)
- 최종 배경을 노란색 그라데이션으로 변경 (위쪽 노란색 → 아래쪽 연한 크림색)
