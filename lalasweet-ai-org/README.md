# 라라스윗 AI 조직 (실습용)

저당 디저트 브랜드 **라라스윗**을 모델로, 사장 겸 디렉터 1명과 AI 직원들이 **신제품 기획부터 출시 마케팅까지** 진행하는 멀티 에이전트 조직을 설계한 실습 저장소입니다.

> **실습용입니다.** 라라스윗(주식회사 오디너리)의 공식 자료가 아니며, 대시보드와 문서에 나오는 수치·콘셉트·제품명·판정은 모두 설명용 가상 예시입니다.

## 한눈에 보기

| 항목 | 내용 |
|---|---|
| 사장 겸 디렉터 | 사용자 · 방향 제시, 콘셉트 선택(승인 1), 최종 확정(승인 2) |
| 비서실장 | Claude Code 메인 에이전트 · 배분·취합·충돌 조정·보고 |
| AI 직원 | 5명 (트렌드 리서처, 제품 기획자, 카피라이터, SNS 콘텐츠 기획자, 검수관) |
| 합류 예정 | 2명 (비주얼 디렉터, 성과 분석가) |
| 운영 단계 | 6단계 + 계획 단계 |
| 실행 방식 | Claude Code 서브에이전트 (`.claude/agents/`) |
| 현재 상태 | 설계 완료 · 시범 운영 전 |

## 대시보드 보기

`dashboard/index.html`을 내려받아 브라우저로 열면 됩니다. 파일 하나로 동작합니다.

- 운영 현황 대시보드 (승인 대기함의 승인·반려 버튼 동작)
- 조직도 (카드를 누르면 직원별 권한·폴더·검토자 표시)
- 프로젝트 재생 시뮬레이션 (승인 단계에서 직접 선택)
- 업무 흐름 6단계 · 비서실장 운영 절차 · 근거 사슬 · 인수인계 양식 · 팀 호출 규칙 · 학습 루프

이전 버전은 `dashboard/archive/`에 있습니다.

## 저장소 구조

```
.
├── README.md                  이 문서
├── CLAUDE.md                  공통 규칙 (Claude Code가 자동으로 읽음)
├── .claude/
│   ├── agents/                직원 5명의 개인 지침 (서브에이전트)
│   └── commands/new-product.md  팀 진행 시작 명령
├── templates/                 지시문·인수인계서·검토서·보고서 등 양식
├── company/learnings.md       프로젝트가 끝날 때마다 한 줄씩 쌓는 학습 기록
├── projects/                  프로젝트별 작업 폴더가 생기는 곳
├── dashboard/                 대시보드 HTML (최종본 + 이전 버전)
└── docs/                      설계 문서
    ├── 01-scope.md            회사·실습 범위·운영 방식 결정
    ├── 02-organization.md     조직도·직급 권한·직원별 상세
    ├── 03-workflow.md         6단계·운영 절차·팀 호출 규칙
    ├── 04-evidence-and-review.md  근거 체계·교차 검토·판정
    ├── 05-gap-analysis.md     참고 조직과의 비교 보고서
    ├── changelog.md           작업 이력
    └── planned-agents/        합류 예정 직원 지침 초안
```

## Claude Code로 써 보기

1. **이 `lalasweet-ai-org` 폴더**를 Claude Code의 작업 폴더로 엽니다. 그래야 `CLAUDE.md`와 `.claude/agents/`가 자동으로 적용됩니다.
2. `/new-product <주제>` 또는 "팀으로 진행해 줘"라고 요청합니다.
3. 비서실장이 `company/learnings.md`를 읽고 팀 설계를 보고합니다. 확인하면 6단계가 시작됩니다.
4. 콘셉트 선택(승인 1)과 최종 확정(승인 2)에서 사장이 결정합니다.

> 직원 지침과 명령 파일은 설계 문서를 바탕으로 만든 **초안**입니다. 시범 운영을 거쳐 다듬을 예정입니다.
