# 04. 근거 체계와 검토

## 근거 사슬 E → I → M → 결과물
- **E (근거)**: 리서처가 `01_research/evidence.md`에 정리하는 관찰한 사실
- **I (인사이트)**: 기획자가 근거에서 끌어낸 해석
- **M (메시지)**: 콘셉트·카피의 축
- **결과물**: 콘셉트, 카피, 릴스 장면은 모두 근거 ID를 적는다

## 꼬리표
| 꼬리표 | 의미 |
|---|---|
| `[확인]` | 직접 본 자료·출처가 있는 사실 |
| `[추론]` | 근거에서 끌어낸 해석 |
| `[가설]` | 근거 없는 추정 — 검증 방법을 함께 적는다 |
| `[미확인]` | 확인하지 못함 — 숨기지 않고 남긴다 |

## 검수 관문 규칙
- 효능·수치 표현인데 `[확인]` E로 이어지지 않으면 → **재작업**
- 사슬이 `[가설]`·`[미확인]`에서 끝나면 → **가장 약한 고리**로 사장 선택지와 최종 보고서의 "못 푼 문제"에 표시
- 사슬이 `[확인]` E까지 이어지면 → **근거 완결**

### 설명용 예시 (가상)
| 결과물 | 사슬 | 판정 |
|---|---|---|
| 릴스 "베어 무는 소리 클로즈업" | M1·M2 → I1·I2 → E1·E2 [확인] | 근거 완결 |
| C안 "여름 한정 파인트" | M3 → I3 [가설] → E3 [미확인] | 가장 약한 고리 |
| 카피 후보 "0칼로리급 가벼움" | 근거 없음 | 재작업 |

## 교차 검토
| 결과물 | 내용 검토 | 표현 검수 |
|---|---|---|
| 리서치 | product-planner | — (내부 자료) |
| 콘셉트 | trend-researcher | quality-reviewer |
| 카피 | product-planner | quality-reviewer |
| SNS | copywriter | quality-reviewer |

- 작성자는 자기 결과를 검토하지 않는다
- 판정: **통과 / 수정 후 통과 / 재작업**
- 재작업 최대 2회, 넘으면 사장 보고
- 검수관은 읽기 전용, 결과는 비서실장이 `reviews/`에 저장
- 양식: `templates/review.md`
