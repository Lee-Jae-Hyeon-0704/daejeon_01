# 업무 지시문 — 비서실장 → <직원>

> 호출할 때마다 6요소를 모두 채운다. 재작업이면 반려 이력을 함께 적는다.

| 항목 | 내용 |
|---|---|
| 프로젝트 폴더 | `projects/<YYMMDD>_<프로젝트>/` |
| 먼저 읽을 파일 | 앞 직원의 인수인계서 경로 · `01_research/evidence.md` · 관련 결정 |
| 할 일 | 범위와 분량 (예: 제품명 후보 10개 → 최종안 1개) |
| 산출물 경로 | 어느 폴더에 어떤 파일로 |
| 완료 기준 | 갖춰야 할 항목 · 근거 ID 표기 · 인수인계서 작성 |
| 쓰기 허용 폴더 | 자기 폴더 + `handoffs/<번호>_<자기이름>.md` |

## 반려 이력 (재작업일 때만)
- 판정자 / 판정 / 사유 / 횟수 (n/2)
- 지켜야 할 결정: `00_brief/decisions.md`의 해당 항목

## 돌려줄 답 형식
① 산출물 경로 ② 핵심 결정 3줄 이내 ③ 미해결·확인 필요
